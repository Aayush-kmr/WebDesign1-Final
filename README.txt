HOW THE HTML WORKS
Each page uses the same simple layout:
header = name and navigation
main = page content
footer = copyright and links

The main content uses basic tags:
section for a part of the page
article for a project
aside for side information
ul and li for lists
h1, h2, and h3 for headings
p for paragraphs
a for links
img for images

HOW THE CSS WORKS
The CSS is split into short sections:
Basic page styles
Header and footer
Shared styles
Home page
Work page
About and contact

The site uses CSS Grid for a few two-column layouts. The media query at the
bottom changes those layouts into one column on smaller screens.


The two main colors are:
#1d5b61 for links and buttons
#9b4c35 for small labels

The fonts load from Google Fonts. The site will use Georgia and Arial if a
visitor is offline.
